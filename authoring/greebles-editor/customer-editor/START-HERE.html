greebles_001 / Customer Editor

Open. Tweak. Paste.

This package is designed for non-technical designers and creative developers. No terminal, npm, or localhost is required. Open the editor, art-direct the greebles, then copy a self-contained embed into your site.

Open Editor Read Quickstart

Best For

Hero sections, moody page backdrops, sci-fi interface surfaces, and landing page texture systems.

Main Export

Copy Iframe Embed gives you a self-contained srcdoc snippet that does not depend on any hosted assets.

Backup Path

If your site builder rejects large inline embeds, use Download Standalone HTML and host or reference that file instead.

Fastest Workflow

  1. 1
    Open OPEN-ME.html and adjust colors, density, glow, and motion.
  2. 2
    Set the embed height that matches the section you are designing.
  3. 3
    Use Copy Iframe Embed to paste directly into Webflow, Framer, or a custom site.
  4. 4
    If the builder is strict about code size, use Download Standalone HTML as the fallback deliverable.
