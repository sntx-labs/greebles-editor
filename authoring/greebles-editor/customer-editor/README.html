Quickstart

How To Use greebles_001

greebles_001 is a sci-fi greeble background generator for websites. The editor is local and self-contained. The exported embed is also self-contained.

Included Files

START-HERE.html

Simple landing page with the fastest path into the product.

OPEN-ME.html

The actual editor. Open this file to customize the greebles.

examples/

Starter snippets and notes for integrating the exported embed into common site builders.

LICENSE.txt

Commercial-use summary and redistribution restrictions for the deliverable.

Export Options

Copy Iframe Embed

Primary export. Produces a self-contained iframe with an inline srcdoc document. Best for Webflow embeds, Framer embeds, and quick placement.

Download Standalone HTML

Fallback export. Produces a single HTML file containing the greeble scene with your current settings baked in.

Copy Config JSON

Utility export. Useful for versioning a look, sharing internal presets, or storing approved art direction settings.

Builder Notes

Webflow

Paste the iframe export into an Embed block. Set the surrounding section height so the iframe has room to render.

Framer

Use an Embed component or HTML block, then paste the iframe export. Adjust the frame height to match your design.

Custom Sites

Paste the iframe snippet into your markup, or host the standalone HTML file if you prefer referencing a separate page.
